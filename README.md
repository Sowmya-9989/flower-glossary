# 🌸 Flower Glossary

A modern and interactive **Flower Glossary Web Application** that allows users to explore flowers through images, search, and concise botanical information.

Built with **HTML, CSS, and JavaScript**, the project focuses on creating a visually engaging, responsive, and user-friendly experience for discovering different types of flowers.

---

## 🌺 Overview

**Flower Glossary** is a front-end web application designed as a digital reference for flower enthusiasts, students, nature lovers, and anyone interested in exploring the world of flowers.

The application combines a clean interface, interactive functionality, flower imagery, and subtle animations to create an engaging browsing experience.

---

## ✨ Features

* 🔎 **Flower Search**
  Quickly search and discover flowers by name.

* 🖼️ **Image Gallery**
  Browse a visual collection of flowers through an interactive gallery.

* 🌸 **Flower Information**
  View useful information and descriptions for individual flowers.

* 🖱️ **Interactive User Interface**
  User-friendly interactions designed for smooth navigation and exploration.

* 🌿 **Animated Petals**
  Decorative petal animations enhance the visual experience.

* 📱 **Responsive Design**
  Designed to provide a consistent experience across different screen sizes.

## 💡 How It Works

The application is built entirely on the client side:

1. **HTML** provides the structure and content.
2. **CSS** creates the visual design, responsive layout, and animations.
3. **JavaScript** handles search functionality and interactive behavior.
4. Flower images and information are presented through the application's user interface.
